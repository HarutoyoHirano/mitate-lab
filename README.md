# mikata-lab（ミカタ・ラボ）

**同じに見える。でも、測り方を変えると違う。**

検査ロボが「区別できません」と言った試作品の、見落としを見つけるゲームです。膝の人工軟骨（かたさと力）、人工血管と心臓ポンプ（力学と電気）、神経の膜（電気）の三つは、同じ一つの回路（電流源＋コンデンサ＋抵抗）で書けます。「見方」を変えて物理・化学・生物をつなぎ、答えを知らない「味方」のAI（Claude）と一緒に証拠を集めます。

## 作品の筋
「同じ」は、測った条件の中での同じにすぎない。測り方や見方を変えると、違いが見える。

1. 止まっているのに、力が変わる（形を固定しても、押し返す力は時間とともに変わる）
2. いつもの検査（最後の数字だけ）では区別できない。本当に同じ？
3. 押す→保つ→離すを一続きで見ると、途中が違う。離したあとのへこみの戻りで、違いが見える瞬間を証拠写真に残す。でも、押し終わりの一点だけでは理由が決まらない。どこを測れば説明が分かれるかを考える（確かめ方を設計する）
4. 分かったことを使って、検査をすり抜ける素材をつくる
5. 同じBを電気回路で書くと同じ線になる（同じ対象の別の表現）。神経細胞の膜でも同じ形の変化が起きる（別の対象への転用）。膜では、イオンの移動（化学）が電流（電気）になり、膜電位（生物の信号のもと）を変える
6. 何をそろえ、何を変え、何が決め手だったかを、自分の記録から一枚に残す

> Built with Claude: Japan 2026 提出作品（テーマ1「あなたにしかない深さを」）

## どんな体験か：検査ロボとの対決
【作成予定：画面の画像】

舞台は再生医療ラボ（仮想）。相手は試作品の検査ロボ KENSA-07（決まった測り方で動く定型ルール。AIではありません）。画面は一画面の舞台で、下のメッセージ窓にロボ・相棒・検算の言葉が出て、行動は二つか三つから選びます。ロボの証言の見落としを、証拠を見せて示し、ロボの自信を崩していきます。

1. **事件1 見破れ（人工軟骨）**：ロボは「押して20秒後の力」で見分ける。膝の試験機で、太ももの骨とすねの骨の間にはさんだ人工軟骨（膝のクッションになる軟骨の代わりを目指す、仮想の試作品）に一歩ごとに体重にあたる力をかけ（テンポを叩く。拍の列が一歩ずつ光る）、毎回ちがう隠れた試料Bと見本Aを比べる。差が出た一歩を証拠にして、ロボに見せる。次に試験台で押して力を記録し、四つの説明を「影武者」として並べ、すべてに札をつけてから、プログラムがまとめて検算する（相棒のClaudeは答えを知らない）
2. **事件2 仕掛けろ（人工軟骨）**：検査規則カードとロボの「次の一手」を見て、すり抜ける試験用の人工軟骨をつくる。ラウンド2で規則が改訂され、前の設計は通らない。クリア後に、計算で塗った「答えの地図」を開く
3. **事件3 拍動の盲点（人工血管・模擬循環回路）**：ロボは「一拍の平均の圧」で見分ける。この模型では平均の圧は末梢の流れにくさだけで決まり、血管のやわらかさにはよらない。拍の中で止めて撮ると、最高と最低が違う。電気回路（電流源＝心臓、コンデンサ＝やわらかさ、抵抗＝末梢）のつまみで同じ波をつくって、正体を確かめる
4. **事件4 膜の盲点（神経の膜）**：膝が押された感じを脳へ伝える神経の端の膜。事件3と同じ回路に電池（静止時 −70 mV）が加わる。全体の図・膜の拡大（外の＋と中の−、押されると開く入口、いつも開いている通り道、中にたまる電荷）・電位のグラフを同じ時刻で動かし、違いが見える瞬間を撮る。通りやすさか容量かを推理し、膜でも二ラウンドの対決（水槽のたとえは切り替えで見られる。この模型は入口で電位が上がって戻るところだけ）
5. **まとめ**：一つの回路に三つの姿。最後の値だけ・平均だけ・戻る速さだけを見ると、それぞれ違いを見落とす。記録から埋まる発見カードと、答えを書かない記録

前の画面は `game.html`、自分で測り方を一から設計できる「詳しい実験室」は `lab.html` に残しています。

## 対象と前提
- 主な対象：医療系の大学生。**ハッカソン期間中の公開デモは大学生以上を対象とします。**
- 素材は**無次元の簡略化した仮想素材**です。人工血管と膜は教科書の簡単な模型（2要素ウィンドケッセル、受け身の膜）で、値は模型の値です。実在の物質・組織・医療機器や体の値を再現したものではなく、診断・病気の判定・操作手順を示すものでもありません。
- 画面の「Claude（AI）」はAIです。隠れた正解を知らず、あなたと同じ証拠だけで考えます。

## 今回の検証範囲
個人（1名）での制作と期間を踏まえ、今回はモデルの整合性と操作の成立を優先し、臨床の現場経験がある同僚1名による使用後の感想と説明内容の確認を予定しています。学生を対象とした試用は行っていません。初学者の理解や興味への効果は設計上の狙いであり、検証済みの成果ではありません。

## 起動方法
Node.js 22 以上が必要です。
1. `npm install`
2. （任意）`cp .env.example .env` を実行し、`ANTHROPIC_API_KEY` と `CLAUDE_MODEL` を設定。設定しなくても、定型のヒントで最後まで動きます
3. 開発用：`npm run dev`（http://localhost:5173）
4. 本番用：`npm run build` のあと `npm start`（http://localhost:8787）
5. テスト：`npm test`

## Claudeの使い方

### 作品の中のClaude（答えを知らない相棒）
- **言葉→候補の翻訳**：学生の自由な説明（例：「Bの方がねばっこい」）を、検証できる候補に翻訳して確認する。確認した候補は保存し、その後の入力に含める
- **根拠つきの問い返し**：構造化出力（根拠にした記録のID・解釈・次の問い・段階）。根拠の記録は画面で光らせる。文章に数字を書いたら1回だけ書き直させ、それでもだめなら定型の手がかりに戻す
- **判断を先取りしない**：学生が自分で判断するまでは、その曲線の判定をClaudeに渡さない（入力の段階で守る）
- **許可ツールでの観察**：学生が予想を置いて了承した押し方だけを `run_observation` で実行する。了承と違う引数では実行させず、失敗したらサーバーが代わりに実行する
- 隠れた正解・真の値・乱数の種は、Claudeへの入力にも画面のコードにも出さない（テストで確認）
- 実APIでの応答の確認は【作成予定】。鍵がなくても、定型の手がかりで最後まで動く

### 開発でのClaude Code
- `CLAUDE.md` を仕様の正本にし、仕様を先に直してから実装（コミット履歴に残る）
- 設計段階で小さな数値試作を作り、誤差の幅・判定規則・原因の組み合わせを数値で決めた
- フック：モデル・比較器を変更するたびに、最悪ケースの誤差を含む識別・判定・秘密分離のテストを自動実行
- サブエージェント：反証役（区別できない条件を探す）、初学者役（画面の言葉・図を点検。膜の電荷の描き方、容量の言い方、しきい値の説明などを直した）
- 別の目による体験レビューを、コードと計算で照合したうえで採否を決めて反映した（経緯の7〜10）

## 試行錯誤の経緯
1. **最初の案（11/2〜3）**：ポンプ・管・センサの仮想装置で「表示が下がった原因」を切り分ける実験室を設計し、数値試作で識別できることまで確かめました。しかし、作者が本当に伝えたかったこと（同じものでも見方で別の面が見える、機械・電気・生体をつなぐ、見えない性質を確かめる実験を設計する、研究の専門性＝血管の粘弾性）から外れていたため、素材版に作り直しました。コミット履歴にポンプ版の仕様が残っています。
2. **「ゆっくり押すと同じ」は成り立たなかった**：数値試作で、遅く押しても差が残ることが分かり、「押して待つと同じ」に問いを直しました。
3. **一点だけ測ると決着しない盲点**：一つの時刻だけを見る計画では、ある範囲の素材が決着しないことを試作で見つけ、「どの瞬間を見るか」を学生が選ぶ体験そのものを中心にしました。
4. **平坦な区間の端点処理**：長く待った点では力がほぼ一定になり、単純な二分法では正しい説明を退けてしまう不具合を、実装前の試作で見つけて仕様とテストに入れました。
5. **実験計画の支援を二段に**：「帯の重なり」だけで次の観察を勧めると、約1割が決着しませんでした。「誤差を2倍にしても分かれる観察」を区別して解消しました。
6. **見方を広げる**：化学は「イオンの移動が電気をつくる」として細胞の膜の等価回路に入れ、「マイナスの抵抗」の思考実験を「さらに先」に置きました（神経の跳ね上がりの始まりだけを直線で近づけたもので、活動電位そのものの再現ではありません）。
7. **テストが通っても、画面は正しくなかった**：別の目で体験を点検したところ、いつもの検査で「誤差の範囲」と固定表示していた（二つの測定の差は誤差の2倍まで広がる）、回路図の配線が並列部分を短絡していた、速くやわらぐ素材にも「時間がかかる」と説明していた、などの不整合が見つかりました。計算の正しさと、画面の値・図・説明の一致は別物だと分かり、判定の許容差を測定誤差と分けて明示し、回路図の配線と説明の向きもテストで照合するようにしました。
8. **爪の色の戻りを入口に使うのをやめた**：体の入口として考えたものの、血流の現象で、素材の力がやわらぐ仕組みとは別でした。画面の中で「止めたまま力が下がる」を見せる入口に替えました。
9. **判定より先に、自分で判断する**：曲線一本で自動的に決着し、考える場面が短くなっていました。比較器の結果を開く前に、本人が「合わなくなった説明」を選ぶ段を入れ、判定は検算として使うようにしました。
10. **何を相手にしているのかが見えなかった**：四角い素材と回路図だけでは、何を押して何を測っているのか、細胞のどこを見ているのかが想像できない、という指摘を受けました。試験機と試験片の図、神経細胞の膜を拡大した図を主役にし、回路図は対応する説明に回しました。あわせて、押し終わりの高さが同じでも途中が分かれる二つの説明を、線を重ねて試せるようにしました（教材の山場を、文章ではなく線で見せる）。

11. **止まっている画面は、ワクワクしない**：深さを保って力の数字を読む実験は、保持中に画面が止まって見えます。「押す→保つ→離す」を一続きにし、離したあとのへこみの戻りを主役の映像と最初の成功（証拠写真）にしました。一方で、形の戻りだけでは区別できない説明の組がある（離す前の力は違う）ことを計算で確かめ、原因の判定はこれまでどおり力の記録で行うことにしました。また、「十分に待てばどちらも平ら」は素材によっては20秒では成り立たないことが分かり、比べる時刻を40秒後にしました。

12. **遊びの骨格を、別の試作から移した**：「検査ロボの盲点」という別の試作（相手がいる・役割が入れ替わる・測り方が変わる第二ラウンド）が、本体よりはっきり面白いことが分かりました。その数値を式で検算したうえで、骨格を本体へ移し、本体の隠れた素材・誤差つきの記録・比較器・Claudeを土台にしました。試作には細胞の話がなかったため、膜の模型で「見破る→推理する→仕掛ける」を新しく作り、膜の対決の第二ラウンド（戻る速さは同じで高さが違う膜）が、素材の「上乗せのかたさ」の違いと同じ形になるように設計しました。

13. **教材のページから、ゲームの画面へ**：説明・カード・グラフが縦に並ぶ画面は、読む側に回ってしまい楽しくない、という指摘を受けました。ゲームの画面を幅広く調べ（相手の言い分に証拠で答える、相手の次の一手を先に見せる、推理をまとめて確かめる、解いた後に解の分布を見せる、など）、一画面の舞台・メッセージ窓・二つか三つの行動に作り直しました。計算と判定はそのまま使い、演出は判定の結果に従わせています。

14. **心臓と血管を、力学と電気をつなぐ題材に**：弾む血管が拍動の流れを受け止めてならすはたらきは、電気回路のコンデンサと同じ式で書けます（ウィンドケッセル）。細胞の膜ともまったく同じ式になるため、素材→血管→膜を一つの回路でつなぐ事件として加えました。平均の圧がやわらかさによらないこと、硬いほど振れ幅が大きいことを、テストで確かめています。
