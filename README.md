# mikata-lab（ミカタ・ラボ）

**ポンプか、管か、センサか。表示の奥にある本当の変化を、AIと実験で突き止める。**

「見方」を変えて同じ装置を調べ、「味方」のAI（Claude）と一緒に証拠を集める謎解き実験室です。臨床工学技士がベテランになって身につける「表示を疑い、駆動・回路・計測を切り分ける考え方」を、学生が安全に何度でも練習できるようにしました。

> Built with Claude: Japan 2026 提出作品（テーマ1「あなたにしかない深さを」）

## どんな体験か
【作成予定：画面の画像と、一周の流れ（予想→予測→計量と駆動電圧→割合か一定量か→振り返り）】

## 対象と前提
- 主な対象：臨床工学科の学生。**ハッカソン期間中の公開デモは大学生以上を対象とします。**
- 装置は**無次元の簡略化した仮想装置**です。実在の医療機器・人体の診断や操作手順ではありません。
- 画面の「Claude（AI）」はAIです。隠れた正解を知らず、あなたと同じ証拠だけで考えます。

## 起動方法
【作成予定】
1. `cp .env.example .env` を実行し、`ANTHROPIC_API_KEY` と `CLAUDE_MODEL` を設定
2. `npm install`
3. `npm run dev`

## 開発でのClaude Codeの使い方（要点）
【作成予定：数行で】

- サブエージェント：反証役（区別できない条件を探す）、初学者役（言葉と操作を点検）
